PT Surya Citra Technology E-Commerce Project

This project was developed during my internship at PT Surya Citra Technology using the Laravel framework.

Project Information

  • Category: Web Design & Development
  • Client: PT. Surya Citra Technology
  • Project Type: Internship Project
  • Technologies: Laravel, PHP, MySQL, JavaScript, RESTful API, Midtrans API
  • Project Date: March 2024
  • Project URL: sct-hardware.site

About This Project

This website was built to support online sales of networking products. The system includes a product catalog, shopping cart, automatic checkout process, and integration with Midtrans for secure online payments.

Similar to the Ocean Space project, this system features an admin dashboard for managing products, orders, and customer data. The backend utilizes Laravel and RESTful APIs for efficient and secure data handling.

Through this internship project, I gained valuable experience in developing full-stack web applications, implementing automated transaction systems, and integrating third-party payment gateways.
